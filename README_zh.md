## ✨ 为什么需要这款工具？
传统的专业声学测试软件（如 Room EQ Wizard / REW、各类 DAW 工作站、专业 VST 效果器插件）充斥着大量的 DSP 专业术语、复杂的倍频程公式（Octaves）和令人望而生畏的操作面板。

而这款应用专为**广大音乐爱好者与数码玩家**量身定制，无需任何声学工程背景，只需 4 步即可调出均衡好声音：

1. **扫频试听**：使用纯净、无爆音的单音频正弦波在 20 Hz 到 20,000 Hz 之间平滑滑动，或开启**自动扫频**，闭上双眼专注捕捉刺耳峰。
2. **当场修正**：当听到某个频点异常刺耳尖锐（高频毛刺峰）或特别微弱（下陷凹坑）时，当场暂停并调节分贝（dB），直到该音高与周围频段听起来一样平滑自然。
3. **上传音乐真实试听**：上传您喜爱的任意音乐音频（MP3、WAV、FLAC 等），直接流式穿透当前 EQ 滤波器组，支持循环播放与拖动进度条。
4. **一键 A/B 盲听对比**：在音乐播放中反复点击“A/B 对比”按钮，直观对比调音前后的音质差别（刺耳高音是否变得顺滑、人声是否更加清晰自然）。
5. **一键导出配置**：一键复制配置，直接粘贴到 Windows 系统的 **Equalizer APO / Peace GUI**、Android 手机上的 **Wavelet / Poweramp**，或 macOS 平台的 **SoundSource / eqMac** 与各类硬件解码耳放中！

## 🔍 核心功能与亮点

- **自定义音乐上传与试听**：支持上传本地 MP3 / WAV / FLAC 等格式歌曲，实时穿透 EQ 滤波器组进行听感校准与无缝 A/B 对比。
- **全双语支持 (Bilingual)**：顶栏支持中英文界面一键即时无缝切换。
- **纯正单频正弦发生器**：基于 Web Audio API 构建，具备平滑淡入淡出（Anti-Pop）防爆音机制，全面保护耳膜与耳机单元。
- **解放双手的自动扫频**：提供“慢速”、“正常”、“快速”三种步进速率，自动从低频向高频爬升，方便戴上耳机专注聆听。
- **54 个关键声学频点卡片**：
  - **低频区 (< 250 Hz)**：极低频震感、重低音下潜、底鼓打击感、贝斯律动（30 Hz, 50 Hz, 80 Hz, 100 Hz, 125 Hz, 160 Hz, 200 Hz 等）。
  - **中频区 (250 Hz – 2 kHz)**：浑浊区、桶音纸盒感、人声温暖度、鼻音（300 Hz, 400 Hz, 450 Hz, 500 Hz, 650 Hz, 800 Hz, 900 Hz, 1 kHz, 1.5 kHz, 2 kHz 等）。
  - **1 kHz 到 20 kHz 步进覆盖**：每隔 0.5 kHz 精细布局，覆盖人耳耳道敏感区、人声清晰度、吉他毛刺区、齿音尖峰、金属镲片飞溅与极高频空气感。
- **通俗易懂的带宽选项**：
  - **窄频 (Q: 4.5)**：精准切除狭窄的啸叫刺耳毛刺峰或陷波。
  - **标准 (Q: 1.41)**：适合大多数耳机常规峰谷微调。
  - **宽频 (Q: 0.71)**：大范围平缓提亮、增温或声底修饰。
- **三点式 Q 值精准测算 (eqbyear 算法)**：扫频聆听时通过按键 `1`（起始点）、`2`（尖峰/中心点）、`3`（结束点）快速标记异常频带，系统自动算出精准中心频率与 Q 值品质因子（$Q = f_c / \Delta f$），并在步骤 1 扫频滑块与步骤 4 曲线图上均呈现直观标定指示，支持一键无缝载入步骤 2 滤镜。
- **无爆音防冲击发声引擎 & 前置 Preamp 架构**：15ms 线性淡入淡出彻底消除振荡器起停时的直流突跳爆音；前级增益置于滤波器组之前，杜绝内部信号削波。
- **透明砖墙式安全限幅 (-0.5 dBFS)**：基于 `WaveShaperNode` 硬限幅曲线，全频段保持 100% 纯线性无染色，彻底摒弃传统动态压缩器的抽吸与起音失真。
- **60 FPS 实时频响可视化曲线与 RTA 光谱**：直观展示当前的复合频响变化，且音乐播放时背景频段随旋律跳动。
- **完整撤销与重做（带提示气泡）**：新增、调整、删除、清空或导入的任何修改均可通过顶栏撤销按钮或 `Ctrl/Cmd + Z` 一键回退，支持 `Shift + Ctrl/Cmd + Z` 或 `Ctrl + Y` 一键重做，并伴有轻量级操作提示气泡。
- **调音会话状态自动持久化**：音量大小、扫频频率、发声模式（正弦/窄带粉噪）及等响度补偿开关均会自动保存，刷新页面不丢失调音进度。
- **主流 EQ 软件一键导出**：
  - **Windows**：Equalizer APO / Peace GUI 标准配置文本（`config.txt`）
  - **Android**：Wavelet AutoEq 与 Poweramp 均衡器格式
  - **Mac / 硬件**：通用参数表格（频率、增益、Q值），适用于 SoundSource、eqMac、Qudelix-5K、MiniDSP 等。

## 🛠️ 本地运行与开发

```bash
# 克隆仓库
git clone https://github.com/Silentishy/peq-tone-generator.git
cd peq-tone-generator

# 安装依赖
npm install

# 启动本地开发服务
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000) 即可开始使用。

### 构建生产包
```bash
npm run build
npm run preview
```

### 运行测试
```bash
npm test            # 运行一次完整单元测试 (Vitest)
npm run test:watch  # 监听文件变化自动重跑
```

测试套件覆盖 `src/utils/eqMath.ts` 中的参数 EQ 核心：Equalizer APO / Wavelet / 通用表格三种导出格式、反向导入解析器（含低音搁架往返回归测试）、RBJ 双二阶滤波器系数与稳定性、解析式频响计算、动态余量 / 前级增益计算，以及画布坐标辅助函数。CI 会在每次推送与 Pull Request 时自动执行类型检查、构建与测试。
